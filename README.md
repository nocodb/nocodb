# NocoDB (FanJam Edition)

This repo is a hard fork of [NocoDB](https://github.com/nocodb/nocodb), an
open-source Airtable alternative used by [FanJam](https://fanjam.live).

This repo forks the upstream project from v0.265.1, the last version licensed
under the AGPLv3, before the project switched to a proprietary source-available
license.

This fork is intended to be FanJam-specific, not a general-purpose continuation
of the upstream project. Features, target platforms, and other complexity may
be trimmed out to reduce the burden of maintaining such a large codebase.
Changes and new feature development may be specific to FanJam.
